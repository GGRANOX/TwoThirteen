# AI Usage Declaration

Жоба барысында AI көмекшісі (Claude Code, Anthropic) қолданылды: жоспарлау, код пен тесттің бастапқы нұсқасын жазу, құжаттама шаблондары.

Қосымшаның өзінде дайын AI API қолданылмайды — барлық алгоритмдер қолмен жазылған.

Автор(лар) кодты оқып, іске қосып, тестілеп, алгоритмдерді түсіндіре алады. *(Растау: қатысушы аты, күні — толтырыңыз.)*
