# Technical Report — TwoThirteen

## 1. Мақсат
Студенттерге AI іздеу алгоритмдерінің жұмысын көрнекі түсінуге көмектесетін интерактивті веб-қосымша (идея №5, AI Algorithm Visualizer).

## 2. Архитектура
Таза JS (ES modules), бэкендсіз. `src/search.js`, `src/localsearch.js`, `src/adversarial.js` — таза алгоритмдер; `src/main.js` — UI. GitHub Pages арқылы статикалық хостинг.

## 3. Алгоритмдер
### Апта 2 — Search (BFS, DFS, UCS, A*)
- **Мақсат:** бастаудан аяқтауға тордағы жол табу.
- **Кіріс:** тор (0 = қабырға, ≥1 = құн), бастау, аяқтау, алгоритм, эвристика.
- **Шығыс:** жол, құн, ашылу реті, ашылған түйін саны, уақыт.
- **Кезеңдер:** ашық жиынтықтан түйін алу → көршілерді кеңейту → g/parent жаңарту. BFS — FIFO, DFS — LIFO, UCS — g бойынша min-heap, A* — f=g+h.
- **Тест:** оптимальдылық (BFS/UCS/A* құны тең торда бірдей), салмақты торда айналма жол, A* түйіндері ≤ UCS, жол жоқ.
- **Шектеу:** DFS оңтайлы емес; BFS салмақты ескермейді; A* оңтайлылығы үйлесімді эвристикаға тәуелді (Manhattan/Euclidean — үйлесімді, 4-бағытты торда).

### Апта 3 — Local Search (Hill Climbing, N-Queens)
- **Кіріс:** N, restarts, seed. **Шығыс:** күйлер тізбегі, h (конфликт жұптары), шешім/жоқ.
- **Кезеңдер:** кездейсоқ күй → ең жақсы көршіге (бір ферзьді бағанда жылжыту) өту → h азаймаса тоқтау → restart.
- **Тест:** табылған күй 0 конфликт және жарамсыз параметрлерде қате.
- **Шектеу:** жергілікті минимум/платолар; restarts қажет; шешім кепілді емес.

### Апта 4 — Adversarial Search (Minimax, Alpha-Beta)
- **Кіріс:** тақта күйі. **Шығыс:** жүріс, баға, қаралған түйін саны.
- **Кезеңдер:** рекурсивті ағаш, терминал бағасы 10−depth / depth−10 / 0; Alpha-Beta `beta ≤ alpha` кезінде кеседі.
- **Тест:** Alpha-Beta бағасы = Minimax; түйін аз; AI X-тің кез келген жауабында жеңілмейді; жеңіс жүрісін таңдайды.
